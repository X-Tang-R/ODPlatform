# docs/architecture (架构决策记录 / ADR)

存放 **Architecture Decision Records(ADR)**——记录"为什么这样设计"。

## ADR 是什么

一份 ADR 记录一次**架构决策**:背景、备选方案、最终选择、理由、后果、撤销条件。

代码能告诉你"现在是什么样",但只有 ADR 能告诉你"当初为什么没选另一种"。

## 什么时候写 ADR

当一个决策**满足以下任一条**时:

- 很难逆转(改起来要动很多地方)
- 有多个合理备选方案,以后可能会有人问"为什么不选那个"
- 影响多个端 / 整个仓库的结构

新增约定:`ADR-002-<简短标题>.md`,编号递增,不重排旧编号。
