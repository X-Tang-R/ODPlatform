# tests (占位)

> 🚧 **状态**: 占位,第二个端到来时才填

本目录是 **跨端(E2E)测试** 的家。

## 放什么、不放什么

| 测试类型 | 放哪 |
|---|---|
| 针对某个端内部逻辑的单元测试 | 该端自己的 `tests/`,如 `apps/platform/tests/` |
| 跨端联动测试(如"起 backend 服务,通过 HTTP 触发 platform 训练") | **这里**,顶层 `tests/` |

跨端测试不属于任何单个端,家在顶层——这是 D0 决定 6 的划分依据。

## 为什么今天是空的?

今天只有 platform 一个端,跨端联动测试无从谈起。第二个端(web-backend)到来时,
这里才会被填满。空置期间不产生任何维护成本。
