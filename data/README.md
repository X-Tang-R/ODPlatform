# data (共享数据)

> 所有端共享同一份数据,物理上只存一份,避免多副本不同步。

## 目录约定

| 目录 | 性质 | 说明 |
|---|---|---|
| `raw/` | **只读** | 原始数据,绝不就地修改。任何处理都生成新副本。 |
| `processed/` | 可再生 | 派生数据,可删了重来。含**固定种子一次性冻结**的 train/val/test 划分。 |

## 两条独立纪律

1. **目录分家** —— 解决"可再生 / 不可变"的边界
2. **冻结划分** —— 解决"评估可比"

> ⚠️ 有了 `processed/` 目录 ≠ 自动不泄漏。
> 训练只读那份固定划分,绝不每次临时 `train_test_split`。

数据集目录结构(D1 §8 检查项):

```
data/raw/<数据集名>/
├── images/
└── annotations/
```

本目录内容不进 git(见 `.gitignore`),走外部存储或 Git LFS。
